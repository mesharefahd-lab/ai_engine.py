# 🛠️ SmartFix AI: AI-Powered Maintenance Management

مشروع مبتكر لأتمتة طلبات الصيانة باستخدام الذكاء الاصطناعي و Python.

## 🌟 فكرة المشروع
بدلاً من فرز طلبات الصيانة يدوياً، يقوم هذا النظام بتحليل وصف المشكلة، تحديد القسم المختص (كهرباء، سباكة، تقنية معلومات)، وتحديد مستوى الخطورة فوراً لضمان سرعة الاستجابة.

## 🧠 تقنيات الذكاء الاصطناعي المستخدمة
- **NLP (Natural Language Processing):** لتحليل البلاغات النصية.
- **Rule-based Expert System:** لاتخاذ قرارات فورية بشأن أولوية البلاغ.

## 🛠️ التقنيات (Tech Stack)
- **Language:** Python 3.10+
- **Framework:** FastAPI
- **Tools:** GitHub Actions, Pydantic
